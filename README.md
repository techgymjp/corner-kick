# コーナーキック (Corner Kick)

サッカーの **コーナーキック** をテーマにしたブラウザゲームです。
選手A がコーナーから蹴り、選手B がヘディングかシュートで合わせてゴールを狙います。全 10 本で何点取れるかを競います。

画面は **操作中の選手の背中越しの3D視点**。ナイター照明のスタジアムで、選手の動き・ボタン・花火・歓声・質感は
techgymjp/jackal(ジャッカル)と同じ作りです。

`index.html` をブラウザで開くだけで遊べます(ビルド不要)。3D描画に同梱の three.js(`vendor/three.min.js`, MIT License)を使っています。
GitHub Pages などの静的ホスティングにそのまま置けます。

## 1 本の流れ

1. **選手A(背番号10)がコーナーキック** — 左コーナーか右コーナーから蹴ります(画面に大きく「左コーナー」「右コーナー」)。
   - 左下の方角リングで **落下地点(黄色の輪)** を動かす
   - 「高く」か「低く」を **長押ししてゲージをため、緑のゾーンで離す** とキック。早すぎると手前に、遅すぎると奥に落ちる
   - 「高く」はふわりと上がって頭の上から落ちてくるボール、「低く」は速いライナー
   - どちらもゴール側へ曲がる(インスイング)
2. **選手B(背番号9)が合わせる** — キックすると選手B に切り替わります。方角リングとダッシュで落下地点へ走り込み、
   - 頭の高さのボールは **ヘディング**(ジャンプして頭で合わせる)
   - 低いボールは **シュート**(ボレー・ダイレクトシュート)
   - ボタンを押すタイミングとボールとの位置が合うほど、速くて正確なシュートになる
   - コースは自動でキーパーのいない側。方角リングを真横に倒していればその側へ
3. **相手の守備**
   - マーカー(相手の4番)が選手B にぴったりついてきて、近くに来たボールは競りに来る
   - ニア・ファー・ゴール前のディフェンダーは、届く高さのボールをクリアする(低いボールはニアで跳ね返されやすい)
   - ゴールエリアに落ちるボールはキーパーが飛び出してキャッチする
   - シュートにはキーパーが反応して横っ飛び。キーパーから遠いほど、速いほど決まりやすい

後半になるほど相手の反応が速くなります。ナビ ON なら、キックの軌道(高く=水色・低く=オレンジ)、ボールに合わせる場所(緑の輪)、
「今押せば当たる」タイミング(足元のオレンジの輪とボタンの点滅)が出ます。

## 操作

| 操作 | タッチ / マウス | キーボード |
| --- | --- | --- |
| 落下地点を動かす(選手A)・選手B の移動 | 左下の **方角リング**(16方位・中心から離すほど速い) | 矢印キー / WASD |
| 高いボールを蹴る(選手A) | 「高く」ボタン長押し → 離す | I(または K)長押し → 離す |
| 低いボールを蹴る(選手A) | 「低く」ボタン長押し → 離す | J(または L)長押し → 離す |
| ヘディング(選手B) | 「ヘディング」ボタン | I(または K) |
| シュート(選手B) | 「シュート」ボタン | J(または L) |
| ダッシュ(選手B) | ダッシュボタン長押し(スタミナ消費) | Shift / Space |
| 一時停止 | — | P / Esc |
| 音のオン/オフ | 画面上部のスピーカーボタン | M |
| ナビのオン/オフ | 画面上部の「ナビ」ボタン | N |

方向は画面基準です(前 = 画面の奥)。

## スコア

- ナイスキック(ゲージを緑で離す): 100
- ゴール: 1000 + ヘディング 300 / ボレー 200 / シュート 100 + 当たりの良さ(最大 200)
- ゴールの隅(ポストの近く)に決めると +200、連続ゴールでボーナス
- コーナーから直接ゴール(オリンピコ)は +1500
- 3 連続ゴールごとに花火を追加
- ベスト記録はブラウザに保存されます。結果画面から X・LINE・コピー・成績画像つきでシェアできます

## 音と演出

音はすべて Web Audio API で合成しています(音声ファイルなし)。

- スタジアムのざわめきと応援(太鼓と手拍子のリズム)。ボールが上がってゴール前に近づくほどどよめきが大きくなる
- キック・ヘディング・ネットを揺らす音・ポストやバーに当たる「カーン」・キーパーのキャッチ
- ボールに合わせた瞬間はスローモーション
- **チアホーン**: キックのゲージをためているとき、ボールがゴール前にある間
- **ゴールで笛・大歓声・拍手・指笛・花火**。ヘディング・隅へのシュート・直接ゴールはさらに派手に
- 外すと観客のため息「あー…」

## 言語

日本語と英語に対応しています。端末の言語が日本語なら日本語、それ以外は英語で表示し、タイトル画面左下のボタンで切り替えられます。
文言は `i18n.js` にまとめています。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `game.js` | ゲームの進行・ボールの物理・選手と守備の動き・入力・2D の表示(HUD・ボタン・ゲージ・ミニマップ) |
| `scene3d.js` | 3D 描画(スタジアム・ゴールとネット・選手・ボール・花火・カメラ) |

## English

**Corner Kick** — a 3D football browser game about scoring from set pieces.

- Play as **Player A** at the corner flag: set the landing spot with the direction ring, then hold HIGH or LOW to charge the kick and release in the green zone.
- After the kick you switch to **Player B**: run onto the ball and hit HEADER (ball at head height) or SHOOT (low ball). Your marker, the zonal defenders and the keeper all try to stop you.
- 10 corners per game. Open `index.html` in a browser to play.
